# PRD — تطبيق إدارة أنشطة الصيانة

**العميل:** الشركة العامة لخدمات الملاحة الجوية

## الهدف
تطبيق موبايل (Expo) باللغة العربية مع دعم RTL لإدارة وتسجيل أنشطة الصيانة اليومية للموظفين، مع لوحة مدير لإدارة الحسابات وإنشاء تقارير أسبوعية قابلة للطباعة والتصدير PDF.

## الأدوار
- **مدير (admin):** ينشئ/يحذف حسابات الموظفين، يعرض كل الأنشطة، ينشئ ويصدّر التقرير الأسبوعي.
- **موظف:** يسجّل نشاطات الصيانة، يطّلع على سجله الشخصي.

## الميزات الرئيسية
1. **المصادقة:** JWT + bcrypt، حساب مدير افتراضي `admin/12345` يُهيَّأ عند بدء الخادم.
2. **استمارة نشاط الصيانة:** اسم الموظف (تلقائي)، التاريخ، طبيعة العمل، القسم (قائمة منسدلة)، ملاحظات.
3. **قائمة الأقسام:** الموارد البشرية، المالي، التدقيق، التخطيط، مكتب المدير العام، الفني، الاتصالات، الحركة الجوية، السلامة، معلومات الطيران، التدريب، الجودة، تمكين المرأة، الإعلام.
4. **لوحة المدير:** إدارة الموظفين (إضافة/حذف)، عرض كل الأنشطة مع فلترة حسب القسم، تقرير أسبوعي.
5. **التقرير الأسبوعي:** يبدأ يوم السبت، إحصاءات مجمّعة لكل موظف، تصدير PDF ومشاركة + طباعة عبر `expo-print` و`expo-sharing`.

## التقنيات
- Frontend: Expo Router + React Native (RTL مفعّل عبر `I18nManager.forceRTL`)، `expo-print`، `expo-sharing`، `@react-native-community/datetimepicker`.
- Backend: FastAPI + Motor (MongoDB) + PyJWT + bcrypt.
- التخزين: MongoDB collections — `users`, `activities`.

## واجهات API الرئيسية (`/api`)
- `POST /auth/login`, `GET /auth/me`
- `GET /departments`
- `POST/GET/PATCH/DELETE /admin/employees`
- `POST /activities`, `GET /activities/me`, `DELETE /activities/{id}`
- `GET /admin/activities` (فلترة بالتاريخ/الموظف/القسم)
- `GET /admin/report/weekly?week_start=YYYY-MM-DD`
